# React & Next.js 작업 규정

- 기존 컴포넌트의 구조와 재사용 패턴을 우선 따른다.
- Next.js App Router의 서버 컴포넌트를 기본으로 사용하고, 상태·이벤트 처리 등 클라이언트 기능이 필요한 경우에만 클라이언트 컴포넌트를 사용한다.
- 'use client' 지시문은 필요한 컴포넌트 경계에만 선언한다.
- 컴포넌트의 책임을 명확하게 유지하고, 서로 다른 역할을 가진 컴포넌트는 적절히 분리한다.
- useEffect는 렌더링 과정이나 이벤트 핸들러로 해결할 수 없는 외부 시스템과의 동기화에 사용한다.
- 기존 프로젝트의 폴더 구조, 라우팅 방식, 컴포넌트 및 스타일링 규칙을 따른다.
